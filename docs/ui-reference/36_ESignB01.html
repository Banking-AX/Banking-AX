접수 완료 확인

교육용 시연 화면이에요. 서명은 화면에서만 동작하는 모의 서명이고, SMS 인증은 휴대폰 소지 확인이에요. 실제 실명확인·법적 전자서명이 아니에요. 서명과 SMS 인증을 마치지 않으면 서버가 실행·제출을 거부해요.
