# UI 화면 목록 — 디자인 시안 기준 (기능명세서 v1.7.1)

> 이 문서는 claude.ai의 디자인 시안(비공개 캔버스)을 Codex가 읽을 수 있게 옮긴 것이다.
> **화면 구조·상태 라벨·버튼·필수 안내 문구의 기준**으로 쓰되, 기능명세서 v1.7.1이나 `01_schema_mysql8.sql`과 다르면 그쪽을 따른다.
> 라우트 경로는 모두 `[제안]`이다. 실제 프론트 구조에 맞춰 바꿔도 된다.

## 0. 모든 화면 공통 규칙

- 화면의 은행명은 가상의 **AX뱅크**이고, 모든 페이지에 "교육용 시연 화면 · 가상 데이터" 표기를 둔다. 실제 은행 로고·브랜드·앱 이름(예: 슈퍼SOL)을 쓰지 않는다. 앱 위임장은 "AX뱅크 앱 위임장"으로 표기한다.
- 문서·코드 안의 "신한은행 공식 양식"은 화면에서 "AX뱅크 공식 양식"으로 표시한다.
- 진행률은 **N/M**으로만 표시한다(예: 필수정보 7/7 · 업로드 서류 1/1). `%` 진행률을 쓰지 않는다.
- 업무 설명·유의사항에는 RAG 근거를 "근거: 문서명 – 절" 형식의 칩으로 붙인다.
- AI 문구에 "승인됩니다", "지급 가능합니다", "대상입니다" 같은 판정 표현을 쓰지 않는다. 결과는 직원이 확정한 원문만 보여 준다.
- 상태는 축별로 따로 표시한다. 처리 상태(case_status), AI 점검 상태(review_status), 예약 상태(visit_reservation.status)를 한 배지로 합치지 않는다.
- 배지 수는 0이면 숨기고, 100 이상이면 `99+`로 표시한다.
