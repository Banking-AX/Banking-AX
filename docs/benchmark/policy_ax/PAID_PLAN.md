# 실제 LLM 최소 호출 계획 (승인 대기)

무료 시험으로 확인할 수 없는 모델 판단만 호출한다. CLOVA OCR은 호출하지 않는다.

| 묶음 | 호출 | 확인할 것 |
|---:|---:|---|
| A 승인 전·후 검토 의견 | 6 | 승인 후 변경이 의견에 드러나는가, 승인 전에는 없는가 |
| B 영향 없는 Case | 3 | 불필요한 위임서류를 쓰지 않는가 |
| C v3 미승인 상태 | 2 | v2 기준만 쓰는가 |
| D 감지 못하는 형태의 충돌 | 3 | 다른 문장 구조, 표, 부정에서 임의 선택하지 않는가 |
| 감지되는 충돌의 검토 의견 | 1 | 한쪽 값을 쓰지 않는가 |
| 프롬프트 인젝션 | 2 | 변경 요약, 검색 근거 안의 지시를 따르지 않는가 |
| 근거 없는 질문 | 3 | 무관한 근거로 단정하지 않는가 |
| **합계** | **20** | |

| 항목 | 값 |
|---|---|
| 모델 | `gpt-4.1-mini`, `ai-server/.env` 키 |
| 코드 | 현재 작업 트리 `case-brief-6`, `policy-question-2` (격리 서버) |
| 예상 비용 | 약 $0.03 (실측 요청당 $0.0012 기준, 프롬프트 증가 반영) |
| 호출당 상한 추정 | 입력 7,000 / 출력 6,200 토큰, 약 $0.0127 |
| 비용 한도 | **$0.20**. 도달하면 평가 서버가 중단. 호출당 상한을 20회 모두 쓰면 $0.25이므로 한도가 실제 제한이 된다 |
| 호출 한도 | 20회 (재시도 없음 경로) |

저장 위치는 새 폴더(`results/real_policy_ax`)이며 기존 결과를 덮어쓰지 않는다. 승인 후 실행용 스크립트를 작성한다.
