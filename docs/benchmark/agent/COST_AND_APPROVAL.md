## 요청하는 승인

- 호출 한도 **150회**, 비용 한도 **$1.00**. 어느 쪽이든 닿으면 평가 서버가 호출을 중단한다.
- 대상은 합성 데이터뿐이다. 실명, 실제 계좌, 고객 서류는 보내지 않는다.
- `ai-server/.env`의 OpenAI 키를 사용한다. 키는 출력하지 않는다.
- 실행 장소는 `127.0.0.1:19501`의 격리 평가 서버다. 공유 DB와 기존 서버는 사용하지 않는다.

## 함께 결정할 것

- OpenAI 모델 문서에 `gpt-4.1-mini`가 deprecated로 표시되어 있다. 이번 측정은 현재 설정된 모델로 하되, 배포 전 교체 여부를 정해야 한다.
- CLOVA OCR 정확도는 이번 평가 범위에 넣지 않았다. 필요하면 합성 위임장과 별도 호출 승인이 필요하다.
