# 계약 폴더 안내

이 폴더는 예시 위치다. 저장소의 기존 계약 구조가 있으면 그것을 사용한다.

- `core/` : 공통 요청 ID, 업무 코드, 사용자 권한, 상태 코드, 오류와 trace ID (팀원 1)
- `auth-verification/` : 모의 서명 완료 확인·SMS 인증번호 발급/검증/1회 소비 요청·응답·오류 코드 (팀원 1)
- `a02/`, `b01/`, `c01/` : 팀원 1의 업무별 Tool API·JSON 스키마·예시
- `a01/`, `b02/`, `c02/` : 팀원 2의 업무별 Tool API·JSON 스키마·예시
- `staff-review/` : 직원 Agent 결과서·검토 결과 공통 응답 타입 (팀원 2)
- `visit/` : 방문 예약·업무코드/업무량 기반 직원 추천 계약 (팀원 2)

공통 계약은 작게 유지한다. 업무별 필드를 공통 DTO에 계속 추가하지 말고 각 업무 계약에서 확장한다. 계약 변경은 별도 PR로 먼저 병합한다.
