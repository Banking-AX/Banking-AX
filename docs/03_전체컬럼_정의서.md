## 변경하지 않은 의도적 설계

- `decedent.deposits`는 조회 전용 Mock JSON. 별도의 예금계좌 테이블은 추가하지 않았습니다.
- `task_result.before_value` / `after_value` / `detail`에 B업무 실행 전후 정보를 저장합니다.
- `work_item.sequence_no`, `resume_step`, `workflow.version`은 이미 존재합니다.
- `case_revision`을 통한 `(case_id, revision)` 복합 FK가 있습니다.
- 예약은 직원 검토 확정·결과 통지 이후만 Spring API에서 허용합니다.
- `case_statement.expires_at`은 30일 정책 대상, `chat_message.sent_at`은 7일 보존 배치 기준입니다.
- 동일 예약/배정의 중복 및 카운터 갱신 원자성은 Spring 트랜잭션과 행 잠금으로 보장합니다.
