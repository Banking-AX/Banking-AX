# C-01 채무조정 사전접수 — 고객 질문 흐름 (초안)

> **구분:** 운영 흐름 초안. 고객에게 확정 가능·승인을 보장하지 않습니다. RAG 본문으로 적재하지 않습니다.
> 근거 문서: `C01-01`, `C01-04`(접수); `C01-05`(사후 조정서, 직원 참고).

| 순서 | 확인할 항목 | 처리 경계 |
|---|---|---|
| 1 | 채무조정 요청 취지 | 실직/폐업/질병 및 사고/소득감소/기타 사유를 수집 |
| 2 | 대상 대출계좌 | Spring Tool로 대출계좌 및 잔액 조회. 본인확인과 접근 통제 |
| 3 | 요청대상 해당 여부 | 신청 대상 기준 안내. 자동 승인/거절하지 않음 |
| 4 | 신청 제한 요인 | 진행 중인 법원·신복위 절차, 재접수 등 조건은 고객 진술과 조회 가능 범위를 구분하고 직원에 이관 |
| 5 | 희망 조정 내용 | 상환유예/기간연장 등 희망사항 기록. 실제 조정 조건 확정 금지 |
| 6 | 필요서류 | 채무조정 요청서, 개인정보 동의서, 변제능력 입증자료, 채무조정안(작성 곤란 시 생략 가능) 안내 |
| 7 | 서류 제출 상태 | 업로드 유무와 형식·기본 기재 항목만 점검, 진위 판단은 직원 |
| 8 | 사전접수 내용 확인 | 본인에게 접수 내용과 직원 확인 필요항목을 보여주고 제출 동의 확인 |
| 9 | ServiceCase 생성 | Spring에서 접수 케이스 영속화. 직원 Agent는 요약·누락 자료 정리만 수행 |

※ 공식 자료상 심사 결과는 거절될 수 있으며 요청 결과 통지에 10영업일 이내 기준이 기재되어 있습니다. PoC의 '사전접수' 완료는 실제 은행 접수 완료를 뜻하지 않습니다.
