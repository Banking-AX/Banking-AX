# B-02 청년 주택드림 청약통장 해지 — 고객 질문 흐름 (초안)

> **구분:** Agent 운영용 질문 흐름. RAG 원문 근거가 아니므로 벡터DB에 적재하지 않습니다.
> **중요:** 공식 상품설명서는 영업점 해지만 가능하다고 안내합니다. 따라서 이 PoC는 **사전안내·서류점검·Mock 시뮬레이션**이며 실제 비대면 해지를 수행하지 않습니다.
> 출처 근거: `B02-01`, `B02-02`; 출처가 확인되지 않은 `B02-03`, `B02-04`는 판정에 사용하지 않습니다.

## 질문 및 처리 흐름

| 순서 | 고객에게 질문/확인할 내용 | 처리 방향 | 근거 |
|---|---|---|---|
| 1 | 어떤 사유로 해지하려고 하시나요? | 일반해지 / 청약당첨 / 특별해지 주장 / 기타로 분류 | B02-01 |
| 2 | 계좌 가입기간은 얼마나 되었나요? | 고객에게 수치를 묻기보다 Spring 계좌조회 Tool로 가입일 확인. 청약당첨 여부와 구분 | B02-01 |
| 3 | 청년주택드림 우대이율을 적용받고 싶으신가요? | 희망 시 무주택 기간 입증서류 안내. 미희망 시 기존 청약통장 이율 적용 동의서 안내 | B02-01, B02-02 |
| 4 | 가입 이후 주택을 취득하거나 재산세 과세 기록이 있었나요? | 지방세 세목별 과세증명서 기본 안내, 과세 이력 있으면 등기부등본/예외 입증서류 추가 확인 | B02-01 |
| 5 | 기존 비과세 신청 내역이 있나요? | 비과세는 우대이율과 별개. 가입·신청 상태를 조회하고 필요하면 직원 확인 | B02-01 |
| 6 | 청년우대형 상품에서 전환한 계좌인가요? | 기존 청년우대형 가입기간의 우대조건 및 추가 주민등록등본이 필요한 특수 사례 확인 | 상품설명서 p.9 (현행 정제본 B02-01에서는 제외된 항목) |
| 7 | 본인이 직접 진행하시나요? | 사망에 따른 상속인 요청 등 특수 상황은 담당자 확인 경로로 전환 | B02-01 |

## 구현 시 안전장치

- **퇴직 특별해지 = 우대이율 보장**으로 해석하지 않습니다. 특별해지는 세제상 추징 예외와 별도로 검토해야 합니다.
- 고객의 '무주택입니다'라는 주장만으로 자동 적격 판정을 하지 않습니다.
- 실제 계좌·금리 상태, 제출 동의 및 처리 상태는 Spring Boot가 관리합니다.
- RAG는 제출서류와 규정의 설명에만 사용합니다.
- `B02-01`의 원문을 기준으로, 미확인 출처 자료는 검색·Rule 판정에서 제외합니다.


## 개발 시 처리 구분

- 자동판정은 Spring의 B2-R1~R6 결과만 신뢰합니다.
- 2년 이내 특별해지의 비과세 추징 예외는 설명만 제공하며 자동승인하지 않습니다.
- 가입기간·계좌상태·청약당첨은 Spring Mock Tool에서 조회합니다.
- 온라인 실제 해지 가능하다고 설명하지 않고 가상 Mock 처리를 구분합니다.
- 우대이율 신청에 따른 과세증명서 대조는 고객 직접 진술만으로 승인하지 않습니다.
