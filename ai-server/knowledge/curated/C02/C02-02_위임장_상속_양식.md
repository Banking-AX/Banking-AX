# 위임장(상속)

## 본문

㈜신한은행 ( )지점 귀중

본인은 아래의 상속재산에 대하여 손해담보약정서 및 청구서의 자필연서가 불가능하여 관련 상속예금 해지(지급)에 관한 모든 일체의 사항을 아래의 대리인에게 위임하여 신청합니다.

## 기재 항목

### 1. 상속재산 (단위: 원)

- 예금주 / 생년월일(주민번호 앞6자리)
- 예금과목 / 계좌번호 / 잔액 / 비고 (3행)

### 2. 대리인 인적사항

- 성명 / 생년월일(주민번호 앞6자리) / 주소 / 본인과의 관계

### 3. 위임인 (5행)

- 성명 / 생년월일(주민번호 앞6자리) / 주소 / 서명(인)

### 작성일 및 은행 확인란

- 작성일: 년 월 일
- 본인의사 확인 및 대리인 실명확인자: 신한은행 ( )(부)지점 / 직책 / 성명 (인)
- 결재란: 담당자 / 확인자 / 부점장

## 하단 안내

- ☞ 위임인 본인의 실명확인증표(사본가능)와 대리인의 실명확인증표 징구
- 위임인의 개인인감증명서 첨부 및 인감 날인
