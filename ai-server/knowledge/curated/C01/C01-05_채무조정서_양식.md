# 채무조정서

## 1. 채무자 기본정보

- 성명 / 생년월일 / 연락처 / 주소

## 2. 채무조정내역

### 1) 조정내용 (단위 : 원)

- 대출명 / 대출계좌번호 / 기타사항 상세
- 조정 전·후 각각 기재: 원금 / 비용 / 이자 / 연체이자 / 합계 / 적용금리

### 2) 채무조정에 따른 변제계획

- 상환유예
  - 분할상환 유예: 차기 ( )회분
  - 이자 유예: 차기 ( )월분
- 상환방식: □ 원리금균등 / □ 원금균등 / □ 만기일시상환 / □ 기타( )
- 상환기간
  - 분할상환 기간: 년 월 일 ~ 년 월 일
  - 이자납입 기간: 년 월 일 ~ 년 월 일
- 매월 납입일: ( )일
- 유예분 상환방법: □ 상환기간 시작일에 한번에 상환 / □ 상환기간 동안 분할하여 상환
- ※ 상환기간 : 대출 잔여기간 - 유예기간

### 3) 납입계좌정보

- 입금은행(신한은행) / 계좌번호 / 예금주명

## 3. 채무조정 합의해지 기준

- 채무조정에 따른 변제계획 불이행 시 납입 관련 안내를 받을 수 있습니다.
  - 신한은행 「채무조정 이행지원」 전용 상담센터 : ☎ 02-2144-9602
- 「개인금융채권의 관리 및 개인금융채무자의 보호에 관한 법률 시행령」 제41조 제1항에 따라 다음의 경우에는 채무조정 합의가 해지될 수 있습니다.
  1. 3개월 이상* 채무조정에 의한 변제계획을 이행하지 않은 경우 (\* 금융위원회가 정하여 고시하는 특별한 사정이 있는 경우에는 6개월 이상)
  2. 채무자가 사망한 경우
  3. 채무자가 실종선고를 받은 경우
  4. 채무자가 변제계획을 이행하는 과정에서 허위사실 신고, 재산의 도피 및 은닉, 기타 책임재산 감소행위 등을 한 사실이 발견되는 경우
  5. 채무자가 채권금융회사등에 채무조정 합의 해지를 요청한 경우
  6. 채무자가 「채무자 회생 및 파산에 관한 법률」에 따른 회생계획인가결정, 변제계획인가결정 또는 면책결정을 받은 경우
  7. 채무자가 「서민의 금융생활 지원에 관한 법률」에 따른 채무조정 등 다른 채무조정절차를 신청하여 확정된 경우
  8. 그밖에 제1호부터 제7호까지에 준하는 것으로 금융위원회가 정하여 고시하는 사유
- 채무조정 합의가 해지된 경우 채무자는 당연히 당해채무의 기한의 이익을 상실하여 곧 이를 갚아야 합니다.
- 채무조정 합의 해지 관련 안내는 우편으로 통지됩니다.

## 합의 문구 및 서명

- 귀 은행로부터 채무조정을 승인받음에 있어 귀 은행에 대해 부담하고 있는 채무를 위와 같이 상환키로 합의합니다.
- 작성일: 년 월 일
- 채권금융회사 : 주식회사 신한은행 ( )지점 (인) / 채무자 : (인 또는 서명)
- 은행 확인란: 본인확인 / 담당자 / 책임자 / 결재권자
