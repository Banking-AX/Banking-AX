# 채무조정 절차와 외부 지원제도

채무조정 요청 → 은행 심사·결과 통지 → 채무자 동의 → 조정서 작성 → 합의 성립의 순서로 안내되어 있습니다. 채무자 동의·조정서 작성 및 합의는 기능명세서 v1.2의 PoC 범위 밖입니다. 관련 외부 기관으로 신용회복위원회·법원의 개인회생·개인파산/면책 등이 소개됩니다.

> 출처가 확인되지 않은 캡처를 사람이 요약했습니다. 검색 및 자동판정에 사용하지 마세요.
